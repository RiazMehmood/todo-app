# Data Model: In-Memory Todo Console Application

**Feature**: 001-todo-console-app
**Date**: 2025-12-07
**Purpose**: Define data structures, entities, and state management

## Entity: Task

### Description

Represents a single todo item with a unique identifier, title, optional description, and completion status.

### Attributes

| Attribute | Type | Required | Default | Validation | Description |
|-----------|------|----------|---------|------------|-------------|
| `id` | int | Yes | N/A | Must be positive integer | Unique identifier, auto-generated |
| `title` | str | Yes | N/A | Non-empty, max 200 chars | Task title/summary |
| `description` | str | No | `""` | Max 1000 chars | Detailed task description |
| `completed` | bool | No | `False` | N/A | Completion status |

### Implementation

```python
from dataclasses import dataclass

@dataclass
class Task:
    """
    Represents a todo item.

    Attributes:
        id: Unique task identifier (positive integer)
        title: Task title (required, non-empty, max 200 chars)
        description: Task description (optional, max 1000 chars)
        completed: Completion status (default False)
    """
    id: int
    title: str
    description: str = ""
    completed: bool = False

    def __post_init__(self):
        """Validate task data after initialization."""
        if not self.title or not self.title.strip():
            raise ValueError("Task title cannot be empty")
        if len(self.title) > 200:
            raise ValueError("Task title cannot exceed 200 characters")
        if len(self.description) > 1000:
            raise ValueError("Task description cannot exceed 1000 characters")
```

### State Transitions

```
[Created] ─(add)───> [Incomplete] ─(complete)───> [Complete]
                           ↑                           │
                           └────────(uncomplete)───────┘

[Incomplete/Complete] ─(update)───> [Incomplete/Complete] (status preserved)
[Incomplete/Complete] ─(delete)───> [Deleted] (removed from storage)
```

### Validation Rules

1. **Title Validation** (FR-001, FR-014):
   - MUST NOT be empty
   - MUST NOT be whitespace-only
   - MUST NOT exceed 200 characters
   - CAN contain unicode characters

2. **Description Validation**:
   - CAN be empty (optional)
   - MUST NOT exceed 1000 characters
   - CAN contain unicode characters

3. **ID Validation**:
   - MUST be positive integer
   - MUST be unique across all tasks
   - Auto-generated by TodoManager

4. **Completion Status**:
   - Defaults to `False` (incomplete)
   - Can toggle between `True` and `False`

## Service: TodoManager

### Description

Manages the collection of tasks and provides CRUD operations. Maintains in-memory state during application session.

### State

```python
class TodoManager:
    """
    Manages todo tasks in memory.

    Attributes:
        _tasks: Dictionary mapping task IDs to Task objects
        _next_id: Counter for generating unique task IDs
    """
    _tasks: Dict[int, Task]
    _next_id: int
```

### Implementation

```python
from typing import Dict, List, Optional

class TodoManager:
    def __init__(self):
        """Initialize empty todo manager."""
        self._tasks: Dict[int, Task] = {}
        self._next_id: int = 1
```

### Methods

#### 1. add_task(title: str, description: str = "") -> Task

**Purpose**: Create and store a new task

**Parameters**:
- `title` (str, required): Task title
- `description` (str, optional): Task description

**Returns**: Created `Task` object

**Validation**:
- Title must be non-empty (FR-014)
- Title max 200 chars
- Description max 1000 chars

**Behavior**:
- Assigns unique sequential ID
- Sets `completed = False`
- Increments `_next_id`
- Stores in `_tasks` dict

**Errors**:
- Raises `ValueError` if title invalid

**Example**:
```python
task = manager.add_task("Buy groceries", "milk, eggs, bread")
# Returns: Task(id=1, title="Buy groceries", description="milk, eggs, bread", completed=False)
```

#### 2. get_task(task_id: int) -> Optional[Task]

**Purpose**: Retrieve task by ID

**Parameters**:
- `task_id` (int, required): Task identifier

**Returns**: `Task` object if found, `None` otherwise

**Validation**:
- ID must exist in `_tasks`

**Behavior**:
- O(1) dict lookup

**Example**:
```python
task = manager.get_task(1)
# Returns: Task(...) or None
```

#### 3. list_tasks() -> List[Task]

**Purpose**: Retrieve all tasks

**Returns**: List of all `Task` objects (may be empty)

**Behavior**:
- Returns tasks in ID order
- Empty list if no tasks

**Example**:
```python
tasks = manager.list_tasks()
# Returns: [Task(...), Task(...), ...]
```

#### 4. update_task(task_id: int, title: Optional[str] = None, description: Optional[str] = None) -> bool

**Purpose**: Update task title and/or description

**Parameters**:
- `task_id` (int, required): Task identifier
- `title` (str, optional): New title
- `description` (str, optional): New description

**Returns**: `True` if updated, `False` if task not found

**Validation** (FR-010):
- Task ID must exist
- If title provided, must be non-empty
- Title max 200 chars
- Description max 1000 chars

**Behavior** (FR-008):
- Updates only provided fields
- Preserves `completed` status
- Preserves ID

**Example**:
```python
success = manager.update_task(1, title="New title")
# Returns: True if task exists, False otherwise
```

#### 5. delete_task(task_id: int) -> bool

**Purpose**: Remove task from storage

**Parameters**:
- `task_id` (int, required): Task identifier

**Returns**: `True` if deleted, `False` if task not found

**Validation** (FR-010):
- Task ID must exist

**Behavior**:
- Removes from `_tasks` dict
- ID is not reused

**Example**:
```python
success = manager.delete_task(3)
# Returns: True if deleted, False if not found
```

#### 6. toggle_completion(task_id: int) -> bool

**Purpose**: Toggle task completion status

**Parameters**:
- `task_id` (int, required): Task identifier

**Returns**: `True` if toggled, `False` if task not found

**Validation** (FR-010):
- Task ID must exist

**Behavior**:
- If `completed = False`, sets to `True`
- If `completed = True`, sets to `False`

**Example**:
```python
success = manager.toggle_completion(1)
# Toggles task 1 between complete/incomplete
```

## Data Flow

### Add Task Flow

```
User Input → CLI Interface → TodoManager.add_task() → Task.__init__() → Store in _tasks
                                    ↓
                             Return Task object
                                    ↓
                             CLI Display → User sees confirmation
```

### List Tasks Flow

```
User Input → CLI Interface → TodoManager.list_tasks() → Retrieve all from _tasks
                                    ↓
                             Return List[Task]
                                    ↓
                             CLI Display → User sees formatted list
```

### Update Task Flow

```
User Input (ID, new data) → CLI Interface → TodoManager.update_task()
                                                   ↓
                                            Validate ID exists
                                                   ↓
                                            Update _tasks[id]
                                                   ↓
                                            Return success/failure
                                                   ↓
                                            CLI Display → User sees confirmation
```

### Delete Task Flow

```
User Input (ID) → CLI Interface → TodoManager.delete_task()
                                         ↓
                                  Validate ID exists
                                         ↓
                                  Remove from _tasks
                                         ↓
                                  Return success/failure
                                         ↓
                                  CLI Display → User sees confirmation
```

### Toggle Completion Flow

```
User Input (ID) → CLI Interface → TodoManager.toggle_completion()
                                         ↓
                                  Validate ID exists
                                         ↓
                                  Flip completed boolean
                                         ↓
                                  Return success/failure
                                         ↓
                                  CLI Display → User sees updated status
```

| get_task | O(1) | O(1) | Dict lookup |

| update_task | O(1) | O(1) | Dict lookup + update |

| toggle_completion | O(1) | O(1) | Dict lookup + update |

**Memory Usage**: Approximately 50 bytes per task → ~50KB for 1,000 tasks (well under 50MB constraint)

## Edge Cases

1. **Empty Title**: Rejected with clear error message (FR-014)
2. **Very Long Title/Description**: Truncated or rejected with error
3. **Invalid Task ID**: Returns `False` or `None`, no exception
4. **Unicode Characters**: Supported (UTF-8 encoding)
5. **Special Characters**: Supported in title and description
6. **Empty Task List**: `list_tasks()` returns empty list `[]`
7. **Deleted Task ID Reuse**: IDs are never reused (simpler, prevents confusion)
